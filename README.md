### 🚀 Projets & Réalisations

#### 🤖 ShopyVerse — E-commerce IA Microservices
Projet académique · Déc. 2025

Plateforme e-commerce avec microservices IA : recommandation de produits par LLM (Llama-3.1 via LangChain), chatbot RAG (Retrieval-Augmented Generation) avec Qdrant, et API core NestJS. Architecture microservices complète avec API Gateway et conteneurisation Docker.

`Python · FastAPI` · `LangChain` · `Llama-3.1` · `TypeScript · NestJS` · `Qdrant` · `Docker`

→ [reco-service](https://github.com/AlexisChartier/shopyverse-reco-service) · [chatbot](https://github.com/AlexisChartier/shopyverse-chatbot-service) · [api-core](https://github.com/AlexisChartier/shopyverse-api-core)

#### 🚁 COHOMA — Transmission 3D Drone
Challenge Ministère des Armées · Juin 2025

Système client/serveur pour la transmission de cartes 3D voxelisées (OctoMap) depuis un drone vers un serveur central. Serveur UDP multithreadé en C++ (ASIO) avec compression zlib, réassemblage de fragments et insertion PostgreSQL. Middleware ROS 2 avec contrôle RSSI.

`C++ · ASIO` · `ROS 2` · `PostgreSQL` · `zlib` · `Docker`

→ [server_udp](https://github.com/AlexisChartier/server_udp) · [pointcloud](https://github.com/AlexisChartier/pointcloudCOMPLET) · [middleware](https://github.com/AlexisChartier/drone_middleware)

#### 🎫 Eventy — Microservices Event Management
Projet académique · Nov. 2025

Architecture microservices Java/Spring Boot pour la gestion d'événements : API Gateway (Spring Cloud Gateway), service discovery (Eureka), user-service avec authentification. Routage dynamique, load balancing et découverte de services automatique.

`Java 21` · `Spring Boot 3` · `Spring Cloud Gateway` · `Eureka` · `Docker`

→ [api-gateway](https://github.com/AlexisChartier/api-gateway) · [eureka](https://github.com/AlexisChartier/eventy-eureka-service) · [user-service](https://github.com/AlexisChartier/eventy-user-service)

#### 🎮 Festival du Jeu — App Fullstack iOS + API
Projet dev mobile · Mars 2025

Application iOS (Swift/SwiftUI, MVVM) pour la gestion du Festival du Jeu de Montpellier : gestion des dépôts, ventes, vendeurs, bilans financiers. Rôles manager/admin. API backend Node/Express avec MySQL, authentification JWT.

`Swift · SwiftUI` · `Node.js · Express` · `MySQL · Sequelize` · `JWT`

→ [iOS App](https://github.com/AlexisChartier/awi-app) · [API](https://github.com/AlexisChartier/FestivalDuJeuAPI) · [React Front](https://github.com/AlexisChartier/Front-AWI)

#### 🌧️ Hydrosciences — Pluviométrie & Data Ops
Stage Data Ops · Montpellier · 2024

Gestion et analyse des données de pluviométrie sur le bassin versant du Verdanson (Montpellier). Applications Shiny (R) avec interpolation spatiale IDW, téléchargement de données. Pipeline Python : récupération FTP, calibration, concaténation, matrices creuses HDF5/MTX.

`Python` · `R · Shiny` · `HDF5 · MTX` · `Leaflet`

→ [GitHub](https://github.com/AlexisChartier/StageHSM)

Serveur HTTP de sondages en temps réel avec WebSockets. État géré en mémoire via Ref ZIO, diffusion temps réel via Hub ZIO. API REST documentée avec Swagger UI (Tapir). Front-end vanilla HTML/JS.

`Scala 3` · `ZIO` · `Tapir` · `WebSocket`
