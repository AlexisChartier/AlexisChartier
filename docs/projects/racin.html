// Contexte

Le projet RACIN, mené avec l'Université Paris Saclay, applique l'intelligence artificielle à l'étude sociologique du cinéma. L'objectif : analyser automatiquement des contenus vidéo pour quantifier la présence et l'impact de l'alcool dans les films, à grande échelle.

// Deux axes d'IA

👁️

Détection d'objets

Computer Vision pour détecter les objets liés à l'alcool (verres, bouteilles, etc.) dans les scènes de films.

🧠

LLM

Large Language Models pour analyser et contextualiser les éléments détectés, extraire des insights sociologiques.

// Pipeline

Films (contenu vidéo) │ ▼ ┌──────────────┐ │ Extraction │ ← Découpage en scènes │ de frames │ / shots └──────┬───────┘ │ ┌──────▼───────┐ │ Computer │ ← Détection d'objets │ Vision │ (alcool, context) └──────┬───────┘ │ ┌──────▼───────┐ │ LLM Analysis │ ← Contextualisation │ │ sociologique └──────┬───────┘ │ ┌──────▼───────┐ │ Résultats │ ← Données quantitatives │ & insights │ pour l'étude └──────────────┘

// Points techniques

// Analyse automatisée

Traitement à grande échelle de contenu vidéo, remplaçant l'analyse manuelle fastidieuse.

// Approche hybride

Combinaison CV (détection visuelle) + LLM (compréhension contextuelle) pour une analyse riche.

// Recherche sociologique

Outil au service d'une étude académique sur la représentation de l'alcool au cinéma.

// Backend

API backend (webPR-backend) pour exposer les résultats et interagir avec les modèles.
