// Architecture

Eventy est une architecture microservices complète pour la gestion d'événements (festivals, concerts, etc.). Le client (application mobile) ne communique qu'avec l'API Gateway, qui route dynamiquement les requêtes vers les microservices internes via Eureka.

// API Gateway

Point d'entrée unique (port 8080). Le routage est défini programmatiquement : chaque route intercepte un pattern de chemin et le redirige vers un service découvert par Eureka.

.route("user-service-route", r -> r .path("/api/users/**") .filters(f -> f.stripPrefix(2)) .uri("lb://user-service") // Load balancing via Eureka )

// lb:// = load balancing client-side via Eureka

// Service Discovery · Eureka

Eureka sert d'annuaire dynamique : les microservices s'enregistrent au démarrage et envoient des heartbeats. Eureka retire les instances qui ne répondent plus. Le dashboard web (port 8761) permet de visualiser l'état du système en temps réel.

// Points techniques

// Routage dynamique

Aucune adresse IP en dur : la gateway découvre les services par leur nom logique via Eureka.

// Load balancing

Répartition de charge client-side avec lb:// — plusieurs instances gérées automatiquement.

// Health checks

Eureka reçoit les heartbeats des services et retire les instances défaillantes.

// Cross-cutting

Centralisation future de l'authentification, rate limiting et logging au niveau de la gateway.
