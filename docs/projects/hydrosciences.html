// Contexte

Stage Data Ops au laboratoire Hydrosciences Montpellier. Le projet concerne la gestion et l'analyse des données de pluviométrie du bassin versant du Verdanson (un petit cours d'eau urbain de Montpellier). Le système couvre toute la chaîne : de la récupération automatique des données brutes sur FTP jusqu'à la visualisation interactive via des applications web.

// Pipeline · Python

FTP (données brutes) │ ▼ main_process.py (cron régulier) ├─ Téléchargement FTP ├─ Concaténation par année + station ├─ Calibration des données ├─ Génération matrices creuses (HDF5 + MTX) └─ Backup hebdomadaire │ ▼ cumul_process.py (cron quotidien) ├─ Téléchargement concaténés ├─ Génération cumuls 7 derniers jours └─ Fichiers CSV journaliers │ ▼ Applications Shiny (R) ├─ VerdansonPluie : carte IDW 7 jours └─ gestionPluvio : analyse période custom

// VerdansonPluie · R / Shiny

Application web interactive permettant de visualiser et analyser les cumuls de pluie sur les 7 derniers jours.

// Visualisation

  • ▸ Carte Leaflet avec interpolation IDW
  • ▸ Bulles proportionnelles à l'intensité
  • ▸ Masque pour limiter la zone d'étude

// Fonctionnalités

  • ▸ Téléchargement des données journalières
  • ▸ Pas de temps configurable (15min → 72h)
  • ▸ Génération automatique via cron

// Points techniques

// Interpolation IDW

Inverse Distance Weighting pour estimer les cumuls entre stations (gstat, R).

// Matrices creuses

Stockage HDF5 + MTX (scipy.sparse) pour les données pluvio compressées.

// Automatisation

Cron jobs : main_process (récupération + calibration) et cumul_process (cumuls quotidiens).

// Calibration

Module de calibration des données brutes avant concaténation et stockage.
